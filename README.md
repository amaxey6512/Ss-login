# SS LOGIN — username/password source revision
For an authorized host application with source access. Import SSLogin.h and call SSLoginPresent on the main thread from a visible view controller; keep protected functionality disabled unless completion returns YES. The library does not auto-inject or lock another compiled library.

The existing HTTPS endpoint is retained but its contract must be updated and verified before entering real credentials: POST JSON username, password, hwid; return HTTP 2xx and JSON boolean valid:true only for an authorized, unexpired, non-revoked account. The server must hash passwords, rate-limit attempts, enforce device policy, and restrict account creation to administrators. No backend implementation or admin dashboard is included. No credentials are saved locally. Recheck authorization on subsequent protected sessions. Do not use real credentials until the endpoint is verified under your control.

Upload the contents of this folder (including .github) to your GitHub repository and run Build SSLogin under Actions. Download its SSLogin artifact. This source revision has not been compiled or tested on iOS; the Linux editing environment lacks the iOS SDK. The original binary remains unchanged.
