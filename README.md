# SS LOGIN standalone prototype
Upload these files to a private GitHub repository. Deploy on a Python hosting service with HTTPS (for example Render). Build command: pip install -r requirements.txt. Start command: gunicorn app:app. Set environment variables ADMIN_PASSWORD and SESSION_SECRET to different long random secrets. Set DB_PATH to a file on a persistent volume; ephemeral hosting loses accounts on restart. Open /admin to create accounts; / is the user login. Test creation, login, revocation and expiration. This is a prototype, not production-ready: add rate limiting, owner MFA, password reset/change, audit logging and backups before real users. No device locking or dylib integration is included. Never put secrets in GitHub.
